# Quick Start

## 1. Requirements

```bash
node --version
hermes --version
```

Node.js 18+ and a working local Hermes CLI are required.

## 2. Install

```bash
git clone https://github.com/YOUR_ACCOUNT/hermes-telegram-chat-ui.git
cd hermes-telegram-chat-ui
```

## 3. Run

```bash
chmod +x start-hermes-chat-ui.command
./start-hermes-chat-ui.command
```

Open:

```text
http://127.0.0.1:8793
```

## 4. Optional PWA

Open the app in Chrome, Edge, or Safari and choose the browser's install/add-to-dock option.

## 5. Stop

Press `Control+C` in the terminal running the server.
